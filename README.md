# Funniest Autocorrect Fail

A make.fun entry for **Funniest Autocorrect Fail**
(`u-zeroxfive-funniest-autocorrect-fail-ddf82154`).

## The entry

One line, under 200 characters, written to `/output/entry.txt` by `main.py`.
It reads as a sincere marriage-proposal text ruined by a single
autocorrect slip: the sender meant to write about holding a *hand*,
and the phone served a deli meat instead — at the worst possible moment.

## Run

```bash
python3 main.py
```

This validates the entry (single line, 1–199 characters, non-blank),
writes `/output/entry.txt`, then reads the file back and re-validates it.
